    Section 5.4 Rank of a Matrix

    Recall that back in Section 5.1, we investigated two of the four fundamental subspaces as Null Spaces (Definition 5.1.5) and Column Spaces (Definition 5.1.6). We also saw how we can find a basis for these two subspaces in Section 5.2. There is actually a cool observation about the relationship between their dimensions.
    🔗

    Example 5.4.1.

    Recall we did an example back in Section 5.2 to find a basis for the null space and the column space of the matrix \(A = \begin{bmatrix} -3 \amp 6 \amp -1 \amp 1 \amp 7 \\ 1 \amp -2 \amp 2 \amp 3 \amp -1 \\ 2 \amp -4 \amp 5 \amp 8 \amp -4 \end{bmatrix}\text{.}\) Example 5.2.17 will link you back to the work if you need a refresher.
    🔗
    If we try finding the dimension of the null space and the dimension of the column space, we may notice that they add up to the number of columns. That is, \(\dim \Nul A = 2\text{,}\) \(\dim \Col A = 3\text{,}\) and \(n = 5\text{,}\) so
    \begin{equation*} \dim \Nul A + \dim \Col A = n \end{equation*}
    Well this makes sense because a basis of \(\Col A\) consists of the columns that contains a pivot position, and a basis of \(\Nul A\) can be obtained using the columns without a pivot position. So every column counts.
    🔗
    🔗
    This observation about the relationship between the dimensions is a fundamental theorem of linear algebra, as it links two of the fundamental subspaces together.
    🔗
    Terminology! The rank of a matrix is the dimension of the column space, and the nullity of a matrix is the dimension of the null space. Then we have the following theorem:
    🔗

    Theorem 5.4.2. Rank-Nullity Theorem.

    Let \(A\) be an \(m \times n\) matrix. Then
    \begin{equation*} \dim \Col A + \dim \Nul A = n \end{equation*}
    That is, the rank plus the nullity equals to the number of columns.
    🔗
    🔗
    The other two fundamental subspaces are the column space and the null space of the transpose. That is, let \(A\) be an \(m \times n\) matrix. Then its four fundamental subspaces are
    • \(\Col A\text{,}\) the column space of \(A\)
      🔗
      🔗
    • \(\Nul A\text{,}\) the null space of \(A\)
      🔗
      🔗
    • \(\Col A^T\text{,}\) the column space of \(A^T\text{,}\) aka the row space
      🔗
      🔗
    • \(\Nul A^T\text{,}\) the null space of \(A^T\text{,}\) aka the left-null space
      🔗
      🔗
    🔗
    If we apply the Rank-Nullity Theorem to \(A^T\text{,}\) then we can find the relationship between the dimension of the row space and the left-null space, as follows:
    \begin{equation*} \dim \Col A^T + \dim \Nul A^T = m \end{equation*}
    And if you think about the connection between the column space and the row space, they should have the same dimension since the number of pivot positions in a matrix should be fixed (unchanged through transpose). That is,
    \begin{equation*} \dim \Col A^T = \dim \Col A \end{equation*}
    This is essentially part of the fundamental theorem of linear algebra, along with the orthogonal condition that we won’t be discussing in this class but it is super obvious (look up something called the "direct sum"), captured in the following diagram.
    🔗

    Theorem 5.4.4. Fundamental Theorem of Linear Algebra.

    Let \(A\) be an \(m \times n\) matrix with \(\rank A = r\text{.}\) Then
    1. \(\displaystyle \dim \Col A = \dim \Col A^T = r\)
      🔗
      🔗
    2. \(\displaystyle \dim \Nul A = n - r \)
      🔗
      🔗
    3. \(\displaystyle \dim \Nul A^T = m - r \)
      🔗
      🔗
    🔗
    🔗
    There are other statements in the fundamental theorem of linear algebra captured in this diagram (i.e., \(\R^n\) is the direct sum of the row space and the null space). Essentially, the fundamental theorem of linear algebra is a collection of results about many properties of the four fundamental subspaces. In this class, all we care about here is the connection between the dimensions of the subspaces.
